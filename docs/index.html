  --output reports/demo

Open reports/demo/report.html in your browser. For real checks, read the authorization and scan-limit instructions first.

01

Owner authorization

Every real site needs explicit permission. Requests are bounded, sequential, within one origin, and subject to robots rules.

02

Evidence and changes

Findings show source and destination URLs. Earlier issues remain unverified when the latest check cannot confirm them.

03

Local, readable output

Save an HTML report and JSON state locally. No account, payment, tracking script or hosted scanner is supplied.

A useful observation, with clear limits

Returned HTML

Checks inspect fetched static HTML and same-origin resource responses. Intentional metadata choices can need no change.

Bounded coverage

Limits apply to the whole run. Access restrictions, byte limits and omitted pages can leave issues unverified.

Further testing

JavaScript, logins, forms, payment flows, accessibility compliance, security and uptime require separate testing.

Help improve the report

Bug reports and format ideas are welcome through GitHub issues. Posts are public: omit confidential reports, client details and credentials. Posting feedback does not opt you into sales messages.
